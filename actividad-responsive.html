🔗 Ejercicio 1: Menú de Navegación Responsivo

El menú actual de TechLaunch se ve amontonado y ordenado en columna. Queremos que en pantallas de Tablet/Escritorio se organice de manera profesional en una fila horizontal con espacio intermedio.

  • Usa una media query para pantallas con un ancho mínimo de 768px.
  • Dentro de ella, cambia el contenedor del menú para que la dirección del flex sea row.
  • Distribuye los enlaces usando justify-content: space-between.

💡 Consejo Práctico:

Al diseñar Mobile-First, escribe primero los estilos por defecto (sin media query) que se aplicarán a teléfonos móviles. Luego, utiliza `@media (min-width: 768px)` para añadir o modificar estilos conforme la pantalla sea más grande.
